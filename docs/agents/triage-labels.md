# Triage labels

Use these mappings when an engineering skill refers to a triage role:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Requires evaluation and an actionable brief. |
| Needs information | `needs-info` | Waiting for information needed to proceed. |
| Ready for an agent | `ready-for-agent` | Actionable agent brief; start only when blockers are resolved. |
| Ready for a human | `ready-for-human` | Requires human action or judgement. |
| Will not be actioned | `wontfix` | Work that will not be undertaken. |

These labels exist on the GitHub repository. They supplement descriptive labels such as `bug`, `enhancement`, and `documentation`.

Issue dependencies represent execution order separately from triage readiness. Update the triage label when the issue's role changes, and preserve unrelated descriptive labels.
