# Metator agent guidance

## Agent skills

### Issue tracker

Track work in GitHub Issues for `jcergolj/metator-for-laravel`, using `gh`. Follow native blocking dependencies before starting an issue. See [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md).

### Triage labels

Use the five canonical triage labels. `ready-for-agent` means the brief is actionable, not that its dependencies are complete. See [docs/agents/triage-labels.md](docs/agents/triage-labels.md).

### Domain docs

This is a single-context repository. Read the root glossary and relevant architectural decisions before working; use the v1 acceptance requirements to guide verification. See [docs/agents/domain.md](docs/agents/domain.md).
